## Featured project

### [Workout Tracker](https://github.com/xuhao246/airtable-workout-tracker)

An Airtable decision-support system that helps me choose exercises based on muscle recovery, recency, available equipment, previous performance, and badminton priorities.

- Designed a relational data model connecting exercises, daily entries, workout history, and muscle recovery
- Built a recommendation score using formulas, lookups, rollups, and adjustable business rules
- Automated session history, recovery updates, exercise enrichment, and actionable Slack reminders
- Created an interface for monitoring 30-day muscle recruitment, workout frequency, and badminton activity
- Documented current data-quality limitations and a normalized child-table design for session metrics

Portfolio snapshot from July 19, 2026: 71 exercises and 441 historical sessions.

**Tools:** Airtable · Zapier · Slack · ChatGPT
